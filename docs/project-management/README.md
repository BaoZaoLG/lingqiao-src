# 项目管理文档

本目录集中保存项目执行过程中产生的计划、报告、任务队列和进度记录，避免在仓库根目录堆放非入口文档。

## 综合计划与报告

- `MASTER_EXECUTION_PROGRESS.md`：总体执行进度
- `CONTINUOUS_EXECUTION_COMMAND.md`：连续执行说明
- `BUSINESS_QUESTIONS.md`：待确认业务问题
- `CROSS_MODULE_REPORT.md`：跨模块问题
- `BUILD_AND_DEPLOY_REPORT.md`：构建与部署报告
- `DATABASE_CHANGE_PLAN.md`：数据库变更计划
- `DEAD_CODE_AND_DUPLICATION_REPORT.md`：死代码与重复代码报告

## Java 迁移

- `JAVA_BACKEND_ARCHITECTURE.md`：Java 后端架构
- `JAVA_API_COMPATIBILITY_MAP.md`：API 兼容映射
- `JAVA_MIGRATION_PROGRESS.md`：迁移进度

## 分阶段执行记录

- `SESSION_01_PROGRESS.md` 至 `SESSION_10_PROGRESS.md`：各阶段进度
- `SESSION_01_TASK_QUEUE.md` 至 `SESSION_10_TASK_QUEUE.md`：各阶段任务队列

这些文档之间的同目录相对引用可继续使用原文件名。仓库入口、构建方式和正式模块边界仍以根目录 `README.md` 与 `docs/architecture/repository-boundaries.md` 为准。
